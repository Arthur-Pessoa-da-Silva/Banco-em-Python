# Banco em Python

Projeto de um sistema bancário desenvolvido em Python para praticar conceitos de programação, funções, estruturas de controle, tratamento de erros, módulos e armazenamento de dados.

## Funcionalidades

* ✅ Cadastro de usuário
* ✅ Sistema de senha
* ✅ Limite de 3 saques
* ✅ Limite de R$ 500 por saque
* ✅ Exibição dos saques restantes
* ✅ Depósitos
* ✅ Saques
* ✅ Consulta de saldo
* ✅ Histórico de transações
* ✅ Data e hora nas transações
* ✅ Tratamento de erros de entrada
* ✅ Salvamento dos dados em arquivo JSON
* ✅ Organização do projeto em diferentes arquivos Python

## Tecnologias utilizadas

* Python
* JSON
* Biblioteca `datetime`
* Biblioteca `os`

## Estrutura do projeto

```text
banco-python/
│
├── main.py        # Arquivo principal do programa
├── banco.py       # Operações bancárias
├── usuario.py     # Cadastro e autenticação
├── dados.py       # Salvamento e carregamento dos dados
├── dados.json     # Dados persistidos do usuário
└── README.md      # Documentação do projeto
```

## Como executar

1. Tenha o Python instalado no computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no terminal.
4. Execute:

```bash
python main.py
```

5. Na primeira execução, faça o cadastro.
6. Digite sua senha para acessar o sistema.
